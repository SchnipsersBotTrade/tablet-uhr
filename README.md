# Uhr und Wetter

Große Uhr und ausführliches Wetter im Wechsel (alle 10 Sekunden), ohne Werbung. Gedacht als Vollbild-Anzeige auf einem Tablet.

- Wetterdaten: [Open-Meteo](https://open-meteo.com/) (kostenlos, ohne Anmeldung)
- Einstellungen über die Adresse, z. B. `?ort=Berlin&lat=52.52&lon=13.41&sek=10&nacht=1`
- Die Einstellungen werden im Browser gespeichert. Danach reicht die Adresse ohne Parameter.
- Antippen: zuerst Vollbild, danach Wechsel zwischen Uhr und Wetter.
- Zwischen 22 und 6 Uhr wird die Anzeige gedimmt (`nacht=0` schaltet das ab).
